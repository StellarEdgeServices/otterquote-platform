# Evidence images

One subfolder per issue: `docs/evidence/<issue>/<stamp>-<slug>.<ext>`.

Rule (Tier A, DECIDED -- Ben/CEO, 2026-09-07): an agent cannot attach a file
to a GitHub issue comment -- there is no scriptable file input for it.
Evidence is therefore committed here and linked from the comment with the
raw.githubusercontent.com URL. Never attempt a native comment-attach.

Retired evidence (test captures, superseded files) moves to `_retired/`
rather than being deleted -- nothing here is ever removed outright.

Built and enforced by `In Flight/bin/evidence-commit.py`.
