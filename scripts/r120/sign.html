R-120 signed review

Sign a human read of a pull request so the R-120 signed review check can verify it. Everything happens in this page with your browser's WebCrypto. This page makes no network calls (it has no scripts or resources from anywhere, and its Content-Security-Policy forbids connections). Your private key is never stored and never sent anywhere — it lives only in the textarea below until you close the tab.

Works from file://. Verified by scripts/r120/verify.mjs against .github/r120-review-pubkey.jwk on main. See Docs/r120-signed-review.md.

1. One-time: generate a keypair

Click once. Put the private JWK in your password manager and never paste it anywhere but this page. Commit the public JWK as .github/r120-review-pubkey.jwk (that PR must itself be signed with the key currently on main).

2. Per PR: sign your read

Only sign after you have personally read the whole diff at exactly this head sha. A signature is bound to the PR number and the head sha; any new commit invalidates it and needs a fresh read and a fresh signature.

Message that gets signed: R-120 owner/repo#pr sha
