# credential-sweep.py allowlist

# Two independent line forms — `path:` and `value:` — see the docstring in
# scripts/credential-sweep.py for the full contract. Every entry below was
# added after running the sweep locally against this tree (calibration run,
# 2026-08-31, gh-1386 wave-3 addendum item 3) and triaging each finding by
# hand. None of these is a live credential; each reason is stated so the
# next person to touch this file can tell a stale entry from a load-bearing
# one without re-deriving the triage.
#
# Adding a new entry: prefer `value:` for a single recurring public constant
# (blinds the sweep for that one literal, everywhere) over `path:` for an
# entire file (blinds the sweep for everything in that file). Reach for
# `path:` only when the file's whole content is structurally exempt — a
# lockfile's integrity hashes, a test fixture's synthetic data — not as a
# shortcut around writing the reason for a `value:` entry.

# --- Lockfiles: npm integrity hashes (sha512, base64) by the hundreds. Not
# --- secrets — they are public content hashes of published npm packages.
